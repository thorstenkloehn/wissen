# Visual Studio Code Scaffolding

Das ist ein wichtiger Befehl, da es ihn leider in Visual Studio Code nicht gibt. Man kann ihn mit dem Terminal ausführen.
Beispiel:
```
dotnet aspnet-codegenerator identity -dc ApplicationDbContext
```
Dann soll Claude Code das übersetzen, die Manage Site auf Deutsch:
```
Prompt : Manage Site übersetzen in Deutsch
```
