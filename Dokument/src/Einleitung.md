# Einleitung

Das Projekt ist ein leichtes CMS-Wissenssystem ohne viele Funktionen. Das soll eine sehr schlanke Website sein. Der Admin kann mit Markdown die Website erstellen. Die Struktur wird mit Kategorien und Unterseiten aufgebaut, als flache Navigationsstruktur wie bei MediaWiki. Es ist eine Art privates Wiki-System.

## Funktionen
* Admin Inhalt erstellen.
* Admin Inhalt bearbeiten.
* Admin Inhalt löschen.
* Inhalt wird mit Versionsgeschichte gespeichert.
* Inhalt wird in der Datenbank gespeichert.
* Backup erstellen mit Backup-XML-Datei wegen Datenbankneutralität.
* Wiederherstellen mit Backup-XML-Datei.

## Warum ASP.NET Core MVC
Das System soll mit ASP.NET Core MVC gebaut werden. Ich finde das sehr sicher, weil die Performance gut und das Datenmodell sehr logisch ist.
